# AGENTS.md

Directus bundle extension with two entries:
- `gallery-grid`: interface for managing M2M file relations as a grid gallery with drag-and-drop reordering and cover selection.
- `gallery-grid-cover`: display that shows the cover image in table views.

## Commands

```bash
npm install
npm run build   # production build to dist/
npm run dev     # watch mode
```

`deploy.sh` is a local helper, ignored by git. No tests, no lint config.

## Structure

```text
src/interface/index.ts       # defineInterface
src/interface/interface.vue  # interface component
src/display/index.ts         # defineDisplay
src/display/display.vue      # display component
```

`dist/` is generated by GitHub Actions on push to `src/**`, `package.json`, `tsconfig.json`; do not edit it manually. Release: entry in `CHANGELOG.md` plus tag `vX.Y.Z`.

## Interface gallery-grid

- Registration: id `gallery-grid`, types `['alias']` (virtual field, no DB column), localTypes `['files']`, group `relational`.
- Options: `folder` (default upload folder UUID), `columns` (1-8, default 4), `quickTags` (JSON array of strings).
- Props: `value` (junction records or IDs), `collection`, `field`, `disabled`, `folder`, `columns`, `quickTags`.
- State item `fileItems[]`: `$uid` (Vue key), `id` (junction ID), `file` (DirectusFile), `is_cover`, `sort`, `tags`.
- Emit format: `[{ id, directus_files_id, sort (1-based), is_cover, tags }]`, `id` is undefined for new items.
- Key functions: `buildEmitValue()`, `onUpload(files)`, `toggleCover(index)` (only one cover), `onSortEnd()`, `confirmRemove()` (unlink, file stays), `confirmDelete()` (deletes file via API), `toggleTag`, `addCustomTag`, `removeTag`.
- The `watch` on `props.value`: with junction IDs it fetches full data from the API and keeps `is_cover` from props (unsaved changes win); without IDs it treats items as new with embedded file data. The `skipNextWatch` flag prevents a re-fetch after the component's own emit.

## Display gallery-grid-cover

- Registration: id `gallery-grid-cover`, types `['alias']`, localTypes `['files']`. Options: `circle` (boolean, default false), `size` (40-400 px, default 200).
- `fields` function must request `${field}.id`, `.is_cover`, `.directus_files_id.id`, `.type`, `.title`; it tells Directus which nested fields to fetch.
- Cover choice: fetch junction items, take the one with `is_cover === true`, otherwise the first. States: spinner, image preview, placeholder icon (files without image), dash if no files.
- Image URL: `/assets/${coverFileId}?width=400&quality=80&fit=contain`.

## Relation discovery and database

Both parts find the junction relation through `relationsStore`, take `junctionCollection` and `fileField`, then query the junction table. The junction table needs: `id` (auto-increment PK), `sort` (integer), `is_cover` (boolean), `tags` (JSON array, optional), FK to the parent collection, FK to `directus_files`.

## Dependencies

`vuedraggable@^4.1.0` (drag-and-drop grid), `@directus/extensions-sdk` (Directus API and stores).
